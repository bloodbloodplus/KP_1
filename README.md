# Система мониторинга расхода сырья

## Постановка задачи

Программа предназначена для **мониторинга технологического процесса** в химическом реакторе по параметру **«расход сырья» (X)**. Программа преобразует измеряемые значения в нормированный показатель качества **Q(X)**, проводит **оперативный контроль** состояния процесса и **статистический анализ** выборки.

### Входные данные:

- **Параметр X:** расход сырья, измеряется в **л/мин**.
- **Диапазон X:** от **10** до **60** л/мин.
- **Штатный режим:** **28–45** л/мин, значения вне этого диапазона рассматриваются как отклонение.
- **Количество измерений в выборке:** N = **70**.

### Формула преобразования Q(X):

$$Q(X) = \begin{cases} \dfrac{(X-28)^2}{3}+10, & \text{при } X < 28 \\ 3(X-36.5)+50, & \text{при } 28 \le X \le 45 \\ 2\sqrt{X-45+1}+60, & \text{при } X > 45 \end{cases}$$

### Оперативный контроль:

- **Базовое значение:** Q₀ = **50.00**, **допустимое абсолютное отклонение:** ΔQ = **11**.
- Сигнал при $|Q - Q_0| > \Delta Q$, то есть состояние **«Норма»** при $39 \le Q \le 61$, иначе **«Отклонение»**.

### Статистический анализ:

- Для **Q[16..33]** вычислить **минимум**, **максимум** и **индекс их расположения** (этап КТ4).

### Ручной расчет (Примеры):

1. **X = 20** (меньше 28): Q = (20 - 28)^2 / 3 + 10 = 64 / 3 + 10 ≈ **31.33** → |31.33 - 50| = 18.67 > 11 → **Отклонение**
2. **X = 36.5** (в диапазоне 28-45): Q = 3*(36.5 - 36.5) + 50 = **50.00** → |50 - 50| = 0 ≤ 11 → **Норма**
3. **X = 50** (больше 45): Q = 2*sqrt(50 - 45 + 1) + 60 = 2*sqrt(6) + 60 ≈ 2*2.449 + 60 ≈ **64.90** → |64.90 - 50| = 14.90 > 11 → **Отклонение**
